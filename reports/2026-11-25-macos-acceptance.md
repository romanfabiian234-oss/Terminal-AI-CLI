## Безопасная ручная проверка

Используй `.venv` в `~/Terminal-AI-CLI-`; никакие ключи и приватные команды не вставляй.

```bash
python3 -m terminal_ai models
python3 -m terminal_ai run -- /bin/echo hello
terminal-ai
```

Внутри `terminal-ai`: `pwd`, `echo hello`, `seq 1 150`; проверь прокрутку, положение приглашения, смену размера окна, `⌘K` и историю. Для контроля вставки используй только безвредные `pwd` и `date` на разных строках; запуск каждого должен требовать собственного Enter. Для отмены — `sleep 10`, затем `Ctrl+C`, затем `echo ready`. `/session on` и реальный Codex проверяются **отдельно**, до включения любых экспериментальных настроек по умолчанию.
