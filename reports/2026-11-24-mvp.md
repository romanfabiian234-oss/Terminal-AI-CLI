# Terminal AI CLI — первый рабочий прототип

**Дата:** 2026-11-24. **Статус:** IMPLEMENTED / LOCALLY TESTED, NOT YET MAC-VERIFIED.  
**Проект:** `romanfabiian234-oss/Terminal-AI-CLI-`.  
**Задание:** терминал в стиле Codex CLI с объяснением над техническим выводом, сменой модели и подключением сервера.  
**Правила:** PerfectSkills / PerfectCode v0.4.0; исходные доказательства остаются в репозитории задачи.

## Реализовано

1. Раздельные компактные блоки команды: заголовок, объяснение, исходный PTY-вывод; ограничение буферов, свёртывание, прокрутка, ввод и прерывание.
2. Детектор результата по коду процесса; правила с осторожными формулировками, без ложного заявления об успешности.
3. Async HTTP streaming: Ollama и OpenAI-compatible, список профилей, переключение, локальный fallback при сбое сервера.
4. Защита от перенаправления сетевых запросов, TLS для удалённых серверов по умолчанию, явное разрешение удалённых профилей, переменные окружения для токенов, частичная маскировка секретов.
5. Прямой PTY для полноэкранных TUI как режим совместимости `:raw`.
6. Конфигурация TOML, диагностика, пакет Python без сторонних runtime-зависимостей, документация запуска и ограничений.

## Проверки

- `PYTHONPATH=. python -m unittest discover -s tests -q` — **16 PASS** на Linux / Python 3.13.5.
- `python -m terminal_ai models` — профиль Ollama выводится.
- `python -m terminal_ai run -- /bin/echo SMOKE_OK` — `SMOKE_OK`.
- Интеграционные тесты: реальная PTY-команда с нулевым и ненулевым exit code; моки потоковых API Ollama/OpenAI; красактирование секретов, правила, ANSI/CR-обновления, отказ удалённого HTTP без разрешения, блокировка HTTP-редиректа.

**Не проверено:** запуск на MacBook Air M5 с Terminal.app и реальным Codex CLI; расход RAM/CPU, качество и скорость Qwen, работа реального удалённого AI-сервера, поведение полноэкранных интерактивных TUI в пользовательской среде, корректная реконструкция всех ANSI/VT режимов. Эти критерии остаются открытыми.

## Границы первой версии и следующие задачи

- Для обычной команды `zsh -lc` запускается отдельный процесс; `cd` сохраняется в приложении, остальное состояние оболочки не сохраняется. Долгосрочная цель — постоянная shell-сессия.
- Для `:raw` AI-описание доступно после выхода, но не поверх полноэкранного интерфейса в процессе работы. Следующий этап — безопасный захват структурированных событий Codex без порчи UI.
- В модели нет универсальной совместимости со всеми проприетарными API; подключаются Ollama и серверы с OpenAI-compatible chat-completions.
- На первом этапе используются Python stdlib / curses вместо непроверенной Rust-сборки; Rust-порт рассматривается после профилирования, если нужны реальные улучшения.
- Репозиторий и исходные коды не содержат модели. Пользователь устанавливает её самостоятельно.
